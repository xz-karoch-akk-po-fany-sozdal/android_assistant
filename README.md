# Ассистент (Android, офлайн)

Локальный голосовой ассистент: Vosk (голос), ML Kit (OCR и перевод), локальные команды. Без телеметрии. В интернет приложение ходит только если вы сами ввели API-ключ или скачиваете языковую модель перевода.

> Проект сгенерирован без возможности собрать его на машине автора. Первая сборка в GitHub Actions может потребовать правки версий (см. «Если сборка упала»).

## Получить APK (без локальной сборки)

1. Создайте на GitHub пустой репозиторий (ветка `main`).
2. Распакуйте `assistant-app.zip` и загрузите **содержимое** папки в корень репозитория (Add file → Upload files; папку `.github` перетащите вместе с вложенными файлами). Закоммитьте в `main`.
3. Откройте вкладку **Actions** → workflow **Build APK**. Он стартует сам при push в `main`.
4. Дождитесь зелёной галочки (10–20 минут при первом запуске; скачивается модель Vosk и зависимости).
5. Откройте запуск → раздел **Artifacts** → скачайте `assistant-debug-apk` (удобнее для установки) или `assistant-release-apk` (unsigned, см. ниже).
6. Релиз с APK: создайте тег, например `v1.0.0` (Releases → Draft a new release → Tag). APK прикрепятся к Release автоматически.

Режим OCR: Actions → Build APK → **Run workflow** → `ocr_mode = bundled` (модель внутри APK) или `unbundled` (по умолчанию, через Google Play Services).

## Установка

1. Скачайте `assistant-debug.apk` на телефон (в Artifacts лежит ZIP — распакуйте).
2. Разрешите установку из неизвестных источников для браузера/файлового менеджера.
3. Установите APK. Release без подписи установится не на все устройства, используйте debug-APK.

## Выдача разрешений

Откройте приложение → ⚙ Настройки → «Разрешения»:

- **Микрофон** — кнопка «Выдать».
- **Служба доступности** — кнопка «Выдать» откроет системные настройки → «Ассистент (жесты)» → включить. На Android 13+ для установленного вручную APK пункт может быть серым: «О приложении» → ⋮ → «Разрешить ограниченные настройки», затем повторите.

## Вызов ассистента

- Свайп вверх из нижнего левого/правого угла (зона чуть выше системной панели; угол и размер настраиваются).
- Долгое нажатие «Назад» (>400 мс). Работает при навигации тремя кнопками или с аппаратной кнопкой. При жестовой навигации кнопки «Назад» нет, используйте свайп из угла.
- Плитка «Ассистент» в шторке (добавьте её через редактирование плиток).

## Включение и выключение

Переключатель «Ассистент включён» в настройках. При выключении служба вызывает `disableSelf()`, оверлей уничтожается, модели закрываются, а процесс приложения завершает сам себя, когда окно закрыто. Включить службу обратно можно только вручную в системных настройках доступности (Android не позволяет делать это программно); кнопка откроет нужный экран.

## Перевод

Настройки → «Перевод»: выберите язык, нажмите «Скачать» для русского и для выбранного языка (по умолчанию только по Wi-Fi). После скачивания перевод работает в авиарежиме. Модели удаляются кнопкой «Удалить». Направление определяется автоматически: кириллица → выбранный язык, иначе → русский.

## API-ключ (необязательно)

Настройки → «Облачная модель»: введите ключ (OpenRouter или любой OpenAI-совместимый), при необходимости Base URL и модель, «Сохранить». Ключ хранится в EncryptedSharedPreferences. Облако вызывается только для вопросов, которые не распознал локальный движок. «Удалить ключ» возвращает полностью офлайн-режим.

## Подпись release (необязательно)

Без секретов собирается `assistant-release-unsigned.apk`. Для подписи создайте keystore и добавьте в Settings → Secrets and variables → Actions:

| Secret | Значение |
| --- | --- |
| `ANDROID_KEYSTORE_BASE64` | `base64 -w0 release.jks` |
| `ANDROID_KEYSTORE_PASSWORD` | пароль хранилища |
| `ANDROID_KEY_ALIAS` | alias ключа |
| `ANDROID_KEY_PASSWORD` | пароль ключа |

Тогда release-артефакт будет называться `assistant-release-signed.apk`.

## Локальная сборка (необязательно)

Нужны JDK 17, Android SDK 34 и Gradle 8.9. Скачайте модель вручную:

```bash
curl -LO https://alphacephei.com/vosk/models/vosk-model-small-ru-0.22.zip
unzip vosk-model-small-ru-0.22.zip
mv vosk-model-small-ru-0.22 app/src/main/assets/model-ru
gradle assembleDebug            # -PocrMode=bundled, -Pabis=arm64-v8a,armeabi-v7a
```

`gradlew` в архив не входит: `gradle-wrapper.jar` бинарный, а в архиве только текст. Workflow использует `gradle/actions/setup-gradle` с Gradle 8.9. Чтобы получить wrapper, выполните `gradle wrapper --gradle-version 8.9`.

## Если сборка упала

- `Could not resolve ...`: проверьте версии в `app/build.gradle.kts` (vosk-android 0.3.47, mlkit translate 17.0.3, text-recognition 16.0.0 / play-services 19.0.0).
- `test -f .../am/final.mdl` в шаге модели: структура архива Vosk изменилась, посмотрите вывод `ls` и поправьте путь.
- Ошибка SDK/лицензий: проверьте шаг «Install SDK packages».
- Нехватка места/памяти: уберите `armeabi-v7a`, оставьте `abis=arm64-v8a`.

## Ограничения (честно)

- ML Kit OCR не поддерживает кириллицу. Для русского текста на экране ассистент читает текст из дерева интерфейса через службу доступности; ML Kit по скриншоту нужен для латиницы и картинок.
- Пока служба доступности включена, процесс приложения живёт (десятки МБ). Нулевое потребление гарантируется только в выключенном состоянии.
- Зоны свайпа в углах перехватывают касания в области своего размера.
- Голос с оверлея зависит от политики Android по фоновому микрофону. Если запись с карточки молчит на вашей версии Android, используйте микрофон в главном окне.
